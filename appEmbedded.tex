\chapter{Embedded data files}
\label{app:Embedded}

In part to comply with journal requirements for data availability, and
also to ensure long-term availability of key datasets beyond the
lifetime of the MLS project, various data files are embedded in the
PDF version of this document, and can be extracted as described below.

Not all PDF readers support such a file-extraction capability. At the
time of writing, the ``Adobe Reader'' software is known to provide the
needed functionality.  File extraction can be accomplished through a
``right click'' (or some similar action, such as ``option-click'') on
the icons below, and selecting ``Save Embedded File to Disk\ldots'' or
some similar option.

Also, for understandable user-security reasons, Adobe Reader defaults
to not allowing \texttt{.tar.gz} files to be extracted from PDF
documents without changing user preferences. Safer \texttt{.txt} and
\texttt{.nc4} files can be extracted without issue.  This means that
while the individual files can be extracted, there is no way we can
provide users the ability easily extract all the information in one
go.
